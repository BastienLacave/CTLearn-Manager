# CTLearn Manager

A compagnon package to CTLearn that enables to manage models to train, test, monitor and benchmark them.

## Documenttion

[Documentation](https://ctlearn-manager.readthedocs.io/en/latest/)


## Development installation
1. Clone the repository:
```shell
git clone https://github.com/BastienLacave/CTLearn-Manager.git
cd CTLearn_Manager
```

2. Install the conda environment:
```shell
mamba env create -f environment.yml
mamba activate ctlearn_manager
```

3. Install the project in development mode with all dependencies:
```shell
pip install -e ".[all]"
```
